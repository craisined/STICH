# STICH
*Style Transfer Interchanging Classical and Humming*

Try at https://stich.craisin.tech, from UCD COSMOS 2026 Cluster 12 :3. Uses [musicnet](https://www.kaggle.com/datasets/imsparsh/musicnet-dataset) and [humtrans](https://huggingface.co/datasets/dadinghh2/HumTrans) as data, and [RAVE](https://huggingface.co/Tangible-Music-Lab/RAVE_models/blob/main/freesoundloop10k_default_b2048_r48000_z16.ts) as an autoencoder.
